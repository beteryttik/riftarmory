# Rift Armory — мод для Minecraft Fabric 1.21.11

Комплекты оружия: Разлом, Дракон, Молния, Призрак + Палка Уничтожения.

## Сборка jar
Нужен JDK 21 и Gradle 9.2.1+.

- Локально: `gradle build` → jar в `build/libs/`
- GitHub Actions: workflow уже внутри (`.github/workflows/build.yml`). Загрузи проект
  в репозиторий GitHub — сборка запустится сама, jar скачай из вкладки
  Actions → артефакты (`riftarmory-jar`).

Установка в игру: Fabric Loader >= 0.18.4, Minecraft 1.21.11, Fabric API, Java 21.
Jar — в папку `mods`.

## Предметы и механики

### Комплект Разлома (булава + копьё выдаются одним крафтом)
- **Булава Разлома** — удар создаёт до 7 ТНТ вокруг цели (шкала −60).
- **Копьё Разлома** — ПКМ: 3 ТНТ в точке прицела (шкала −40, мимо −20, кулдаун 30 с).

### Комплект Дракона
- **Булава Дракона** — поджигает цель на 5 секунд.
- **Копьё Дракона** — «Драконий рывок»: телепорт к точке прицела + кольцо пламени
  (радиус 2 блока). Проверки: вода/лава/небезопасная точка = сорванный рывок
  (возврат 25 шкалы). Шкала −50, кулдаун 30 с.

### Булава Молнии
- Цепная молния до 3 целей (100% → 75% → 50% урона). В дождь бьёт и по тебе (4 ед.).

### Комплект Призрака (легкий путь)
- **Булава Призрака** — Shift+ПКМ: фаза неосязаемости (Resistance V + Slow Fall, 2 с).
- **Копьё Призрака** — фазовый бросок: поражает цель до 24 блоков, сквозь стены.
- Путь получения: Алмазный стержень ×2 + Призрачное стекло (4 стекла + светокаменная пыль).

### Палка Уничтожения
- ПКМ: сетка ТНТ 17×17 (289 шт.) на высоте 40 блоков над игроком, детонация почти
  синхронная. Одноразовая. Описание: «Уничтожит этот сервер к чёрту».

### Общая шкала стержня
Хранится в компоненте CUSTOM_DATA предмета (`rift_stability`, макс. 100).
Тратишь на способности; на 0 способности отключаются до восстановления (восстанавливается
со временем в RiftMaceItem и других проверках — см. код).

### Сундуки-разломы
Каждые 20 минут около случайного игрока (200–300 блоков) спавнится сундук:
70% Фрагмент пустоты, 30% Осколок пустоты.

## Крафты
Все рецепты в `src/main/resources/data/riftarmory/recipe/`.
Алмазный стержень: 2 алмаза + редстоун → 2 стержня.

## Известные ограничения
- Код написан под Yarn 1.21.11 без компиляции — если Gradle ругнётся на 1–2 имени
  метода, поправь по тексту ошибки (обычно сигнатуры cooldown или ToolMaterial).
- Булавы — кастомные SwordItem, не ванильные (как и договорились).
